## 2. 제출용 본문 (그대로 복사)

```
=== 1. 체험 계정 및 로그인 방법 ===

PageMate는 소셜 로그인(카카오/구글)만 제공하므로, 심사를 위해 앱 안에 체험 계정을
준비해 두었습니다. 별도의 아이디나 비밀번호는 필요하지 않습니다.

로그인 화면 하단으로 스크롤하면 "체험 계정으로 둘러보기" 아래에 버튼이 두 개 있습니다.

  1) "민준으로 시작 · 빌리는 사람"   — 책을 빌리는 쪽
  2) "서연으로 시작 · 빌려주는 사람" — 책을 빌려주는 쪽

두 버튼 중 하나를 누르면 즉시 로그인됩니다.

[중요] 계정을 두 개 제공하는 이유
PageMate는 이웃 간 1:1 도서 대여 서비스입니다. 요청 수락, 약속 일정 잡기, 책 전달,
반납, 후기 작성 등 모든 단계가 상대방의 동작을 필요로 하기 때문에, 계정 하나만으로는
전체 흐름을 확인할 수 없습니다. 민준과 서연은 서로의 거래 상대이므로, 로그아웃 후
다른 계정으로 전환하면 실제 대여 한 건을 처음부터 끝까지 완주해 보실 수 있습니다.

두 계정에는 모든 단계의 대여 건이 미리 준비되어 있습니다
(요청 대기 / 수락됨 / 약속 완료 / 일정 확정 / 책 전달 완료 / 반납 완료 / 거래 완료).
따라서 로그인 직후부터 모든 화면이 채워진 상태로 보입니다.

=== 2. 테스트한 기기 및 OS 버전 ===

- iPhone 15 Pro — iOS 18.5
- iPhone 12 — iOS 17.6
- iPad (9세대) — iPadOS 17.6  ※ 태블릿 전용 레이아웃 미지원, iPhone UI로 동작
(제출 전에 실제로 테스트한 기기 목록으로 반드시 교체할 것)

=== 3. 앱의 기능과 대상 사용자 ===

PageMate는 한국의 독서 이용자를 위한 동네 기반 도서 "대여" 앱입니다.

해결하려는 문제: 다 읽은 책은 책장에서 몇 년씩 잠들어 있는 반면, 두 블록 떨어진
이웃은 바로 그 책을 읽고 싶어 합니다.

제공하는 가치: 사용자는 자신이 보유한 책을 등록하고, 이웃이 올린 책을 둘러보다가
빌리고 싶은 책에 대여를 요청합니다. 채팅으로 시간과 장소를 정해 직접 만나 책을
건네고, 약속한 반납일에 돌려받습니다. 반납이 끝나면 서로 평가를 남깁니다.
책이 주인에게 돌아가는 "대여" 모델이며, 중고 판매나 영구 교환이 아닙니다.
앱 내 결제는 존재하지 않습니다.

대상 사용자: 정기적으로 책을 읽고, 배송보다 동네에서 직접 만나는 것을 선호하는
한국의 성인 독자(18세 이상)입니다.

앱은 무료입니다. 인앱 결제, 구독, 광고가 모두 없습니다.

=== 4. 주요 기능 접근 경로 ===

체험 계정으로 로그인한 뒤:

- 홈 탭: 이웃이 등록한 책 목록. 책을 누르면 상세 화면
- 검색 탭: 제목·저자 검색, 장르 및 동네 필터
- 책 등록: 홈 > "도서 추가"(+) — 사진 또는 카메라 권한이 필요합니다
- 대여 요청: 책 상세 화면 > "대여 요청" 버튼
- 교환 탭: 진행 중인 모든 대여 건을 단계별로 확인
- 채팅 탭: 각 거래에 연결된 대화. 텍스트와 사진 전송 지원
- 후기: 반납이 완료된 거래에 "후기 남기기" 버튼이 나타납니다
- 마이 탭: 프로필, 내 도서, 동네 설정, 알림 on/off

신고 및 차단 (App Store 심사 지침 1.2 대응):
- 사용자 신고: 상대 프로필 화면 > 우측 상단 "···" 메뉴 > 신고하기
- 도서 게시물 신고: 책 상세 화면 > "···" 메뉴 > 신고하기
- 개별 채팅 메시지 신고: 상대방의 말풍선을 길게 누르면 신고 창이 열립니다
- 사용자 차단: "···" 메뉴 > 차단하기
  차단하면 서로의 프로필·등록 도서·채팅이 보이지 않고,
  새로운 대화나 대여 요청을 주고받을 수 없습니다
- 차단 관리: 마이 탭 > 설정 > 차단한 사용자 > 차단 해제

계정 삭제 (App Store 심사 지침 5.1.1(v) 대응):
- 마이 탭 > 설정 > 회원 탈퇴 > 2단계 확인
- 개인정보를 모두 익명 처리하고, 진행 중인 대여를 취소하며,
  등록한 도서를 목록에서 내리고, 기존 로그인 세션을 즉시 무효화합니다

=== 5. 사용 중인 외부 서비스 ===

- 카카오 로그인 (OAuth 2.0)      — 사용자 인증
- 구글 로그인 (OAuth 2.0)        — 사용자 인증
- 카카오 도서 검색 API           — 책 등록 시 서지 정보(제목·저자·출판사·표지)
- 카카오 로컬 API                — 좌표를 동네 이름으로 변환
- Cloudinary                     — 이미지 저장(프로필 사진, 채팅 사진)

- Railway                        — 서버 및 데이터베이스 호스팅

AI 서비스, 결제 대행사, 광고·분석 SDK는 사용하지 않으며,
앱이나 웹사이트를 넘나드는 사용자 추적도 하지 않습니다.

=== 6. 지역별 차이 ===

이 앱은 대한민국 전용 서비스입니다.

인터페이스와 모든 콘텐츠가 한국어이며, 동네 검색이 한국 주소 데이터베이스를
사용하기 때문에 한국 밖에서는 실질적인 이용이 어렵습니다.
다만 사용자의 지역이나 스토어프론트에 따라 기능을 잠그거나 다르게 동작시키는
처리는 전혀 없으며, 앱의 동작은 모든 지역에서 동일합니다.

=== 7. 규제 산업 및 제3자 권리 ===

PageMate는 규제 산업에 해당하지 않습니다. 결제·금융 서비스를 다루지 않고,
의료나 건강 정보도 취급하지 않으며, 사행성 요소도 없습니다.

도서 정보에 대하여: 이 앱은 저작권이 있는 책의 내용을 일절 유통하지 않습니다.
카카오 도서 검색 API(정식 등록하여 사용 중인 공개 개발자 API)에서 받아온
서지 정보(제목, 저자, 출판사, 표지 썸네일)만 표시합니다. 실제 책은 사용자
본인의 소유물이며, 개인 간에 오프라인으로 대여됩니다. 앱이 책의 내용을
전송하거나 저장하는 일은 없습니다.

앱에 올라오는 사진은 모두 사용자가 직접 업로드한 것(본인의 책 표지, 채팅 사진)
입니다. 사용자 생성 콘텐츠는 위 4번에 설명한 앱 내 신고·차단 기능으로
관리하고 있습니다.
```
